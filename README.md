# 🟣 Sortix

## ✨ О проекте
**Sortix** — это десктопное приложение на **C# / Windows Forms**, которое в реальном времени визуализирует работу классических алгоритмов сортировки и замеряет их производительность.
Каждый алгоритм запускается **5 раз** для точного замера, а затем **воспроизводится** в виде анимированных столбцов — вы видите каждое сравнение и каждый обмен элементов.

## 🎯 Возможности
Алгоритмы сортировки
В программе реализовано пять классических алгоритмов сортировки, каждый из которых можно включать и выключать независимо от остальных. Пузырьковая сортировка — простейший алгоритм с многократными проходами по массиву, наглядно демонстрирующий принцип обмена соседних элементов. Сортировка вставками строит отсортированную последовательность, постепенно вставляя каждый новый элемент в нужное место. Шейкерная сортировка является улучшенной версией пузырьковой и проходит массив в обоих направлениях. Быстрая сортировка использует стратегию «разделяй и властвуй» с выбором опорного элемента. BOGO сортировка работает методом случайных перестановок и добавлена в качестве демонстрации неэффективного подхода — её можно запускать только на массивах до 10 элементов.

Замер производительности
Каждый выбранный алгоритм запускается пять раз подряд на одинаковых исходных данных, что позволяет получить статистически достоверные результаты. Программа замеряет среднее, минимальное и максимальное время выполнения, количество итераций, число сравнений и число обменов элементов. По завершении всех замеров определяется самый быстрый алгоритм по среднему времени. Для BOGO сортировки выполняется только один прогон из-за её крайне низкой эффективности.

Визуализация в реальном времени
После фазы замеров программа воспроизводит работу каждого алгоритма в виде анимированных столбцов. Жёлтым цветом подсвечиваются сравниваемые элементы, белым — обмениваемые. Длительность задержки между шагами регулируется ползунком от 0 до 100 миллисекунд, что позволяет как ускорить просмотр, так и замедлить его для детального изучения. Визуализация автоматически отключается, если в массиве больше 50 элементов — иначе столбцы становятся слишком узкими для восприятия.

Источники данных
Данные для сортировки можно вводить тремя способами. Ручной ввод позволяет заполнить таблицу произвольными целыми числами прямо в интерфейсе. Случайная генерация создаёт заданное количество чисел в указанном диапазоне от минимума до максимума. Импорт из Excel поддерживает файлы форматов .xlsx и .xls, считывая числовые значения из первого столбца. Импорт из Google Sheets работает по публичной ссылке на таблицу — поддерживаются как CSV-формат, так и HTML-формат на случай проблем с доступом.
